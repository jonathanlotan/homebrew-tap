# Homebrew tap for Swivel

[Swivel](https://github.com/jonathanlotan/Swivel) is a free, open-source, offline file converter
for macOS: drag a file, tap a key, drop it on the wheel.

```bash
brew install --cask jonathanlotan/tap/swivel
```

This installs Swivel.app (signed and notarized) and the `swivel` command line.
